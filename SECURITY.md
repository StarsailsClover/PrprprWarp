# Security policy

Do not publish captured archives as issue attachments. They may contain private
page content, authenticated API responses, URLs, or scripts.

For a vulnerability in PrprprWarp itself, report it privately through GitHub's
security advisory interface. Include the affected version, a minimal
reproduction, and whether the issue affects snapshot, live replay, or both.

Do not include real credentials, cookies, or user archives in a report.
